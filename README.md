# 🏛 패권 (HEGEMONY) — 위임형 현대 국가 전략 시뮬레이션

[sam](../sam)(실시간 지도 전술)·[컴퍼니](../컴퍼니)(경제·주식)·[디팬스](../디팬스)(영토 디펜스·저트래픽 구조)를 하나로 합친 게임입니다.
유저는 **돈을 어디에 얼마나 쓸지 비율만 정하는 지도자**이고, 실제 건설·연구·모병·투자·전투는 장관들이 자동으로 집행합니다.

- 현대 배경, 문명식 **기술 트리**(3시대 32개) — 기계화→기갑, 항공공학→항공전대처럼 병종을 해금하고 티어를 올립니다
- 컴퍼니식 **경제** — 광산·시추소·농장·공장, 수요·공급 자재 시장, 5개 글로벌 종목 주식, 유지비
- sam식 **실시간 지도 전술** — A* 행군, 상성 교전, 도시 포위·점령, 부대가 지나간 땅은 실시간으로 뺏기고 빼앗깁니다
- 디팬스식 **저트래픽 멀티플레이** — diff 패치, 1Hz 갱신 + 클라이언트 보간, 웹소켓 전용, 백그라운드 절전
- 음성 채팅(WebRTC P2P), 채팅, 방 코드 멀티, 컴퓨터 국가 — 기존 편의 기능 그대로

## 실행

```bash
npm install
npm start          # http://localhost:7870
npm test           # 규칙·방·diff 테스트
npm run balance    # 봇 4국 20분 자동 대전 (밸런스·성능)
```

대기실에서 🤖 컴퓨터를 추가하면 혼자서도 바로 해 볼 수 있습니다. 같은 방 코드로 들어오면 같은 게임입니다 (최대 6국).

## 플레이 (유저가 정하는 것은 5가지뿐)

| 탭 | 정하는 것 | 집행하는 장관 |
|---|---|---|
| 국정 | **예산 비율** 산업/연구/국방/금융/비축 | 흑자(순수입)가 비율대로 각 부처 금고에 쌓입니다. 비축은 지도자의 저축 — **특별 집행**으로 25/50/100%를 원하는 부처에 한 번에 투입하고, 안 쓴 금고는 **회수**할 수 있습니다. 옵션으로 자동 재배분(순수입 60초분 초과분) |
| 국정 | **군사 교리** 수비/확장/공격 비율 + 공격 대상국 | 국방부가 부대 임무를 이 비율로 배정합니다 (비율을 바꾸면 즉시 재배치) |
| 산업 | **산업 정책** 자원/공장/기반/국방시설 비율 | 산업부가 도시 부지에 건물을 짓습니다 |
| 과학 | **연구 목표** 기술 클릭 | 과학부가 선행 기술부터 경로대로 연구합니다 |
| 금융 | **포트폴리오** 5종목 비중, 전량 현금화 | 재무부가 금융 금고로 매수하고 적자면 매도합니다 |

부대는 선택 후 우클릭(모바일: 길게 누르기)으로 직접 명령할 수도 있지만, 목표에 도착해 25초 쉬면 다시 교리에 따라 위임됩니다.

### 경제
- 수입 = 영토 타일 × 0.045 + 인구 × 0.016 + 공장 판매 + 배당. 지출 = 부대 유지비 + 건물 유지비 + 부족 재료 매입.
- 공장은 철강 0.3 + 원유 0.15 를 먹고 공산품 1.5/초를 만들어 **시장에 즉시 판매**합니다. 재료가 모자라면 시장에서 사 옵니다 (비쌉니다).
- 도시 부지는 건물 **종류** 수를 제한하고, 증설(최대 Lv5)은 부지를 더 먹지 않는 대신 비용이 1.35배씩 오릅니다. 쓸 곳이 없어 2,500 넘게 남는 산업·국방 금고는 자동으로 투자로 돌아갑니다.
- 자재 시장은 전 세계 공용 — 사면 오르고 팔면 내리며 기준가로 돌아옵니다. 120 이상 쌓인 자재는 자동 매도.
- 곡물은 인구를 먹여 살립니다. 남으면 인구 증가(=세수 증가), 모자라면 감소.
- 현금이 마이너스면 부대가 급여 미지급으로 이탈합니다.
- HUD 의 💰 는 **가용 현금**(금고에 배정되지 않은 비축)입니다. 각 부처 금고는 국정 탭에서 보이며, 장관은 2초마다 금고가 허락하는 만큼(최대 6건) 집행합니다. 비축을 모아 두었다가 전쟁이 터지면 국방부에 100% 투입하는 식으로 씁니다. 봇은 자동 재배분이 기본으로 켜져 있어 돈을 묵히지 않습니다.

### 주식 (5종목)
| 종목 | 무엇을 따라가나 |
|---|---|
| 한성방산 | 전 세계 전투 격렬도 |
| 대륙에너지 | 원유 시세 |
| 네오텍 | 전 세계 연구량 |
| 태평건설 | 전 세계 건설량 |
| 푸른식품 | 안정 (배당 높음) |

주기적으로 사건(원유 급등·흉작·기술주 랠리·경기 침체…)이 터져 시세와 자재값을 흔듭니다.

### 군사
- 병종 5종: 보병(기본) / 기갑(기계화) / 포병(야포, 사거리 3) / 항공(항공공학, 지형 무시, 속도 6) / **구축함대**(해군 공학, 바다 전용, 함포 사거리 3).
- 상성: 기갑>보병, 항공>기갑, 포병>보병, 보병>포병(근접), 항공>함대, 함대>포병·보병. 보병·기갑은 함대를 공격할 수 없습니다. 대전차 미사일·휴대 방공 기술로 보병의 약점이 메워집니다.
- **해군**: 해안 도시(반경 3 안에 바다)에 **항구**를 지으면 함대를 편성할 수 있고 항구는 교역 수입(+12%/Lv)도 줍니다. 함대는 적 해안 도시 앞바다로 가서 포격하고, 항구 앞바다에서 보충됩니다. 미사일 구축함(사거리 +1)·항모 전단으로 티어가 오릅니다. 포병·함대는 사거리 밖에서 도시를 포격할 수 있지만 점령은 지상군만 합니다.
- 부대 유지비는 초당 모병비의 약 0.25%. 6기를 넘기면 초과 1기당 부대당 유지비 +4% (대군 억제). 병영·수도에 주둔하면 병력이 회복됩니다.
- 공격 임무 지상군은 목표에 가장 가까운 아군 도시에 **3기 이상 모인 뒤** 진격합니다 (각개격파 방지). 포위된 도시의 국방부는 3기를 모아 한꺼번에 편성합니다.
- **상성 인식 위임**: 도시 위협을 병종별로 분석해, 통하지 않는 부대(항공 상대의 기갑·포병, 함대 상대의 보병·기갑)는 그 도시 수비에 보내지 않고 공격 목표에서도 제외합니다. 반격할 수 없는 적에게 맞고만 있는 지상군은 방공포대가 있는 아군 도시로 물러납니다. 국방부는 지금 내 도시를 치는 적 구성에 맞춰 대응 병종(항공 위협→항공·방공포대·휴대방공 보병, 기갑→항공·포병, 함대→항공·함대)을 우선 편성하고, 산업부는 항공 위협 도시에 방공포대를 최우선으로 짓습니다. 군사 탭에 **위협 분석**이 표시됩니다.
- 도시는 체력이 있고(벙커로 증가), **민병대**가 인접 적 지상군에 피해를 줍니다. 체력 0 + 아군 수비대 없음 + 적 지상군 9초 점거면 넘어가며, 점령된 도시는 건물 40%·인구 70%만 남습니다. 방공포대는 항공기를 격추합니다.
- 도시가 6개를 넘으면 초과 1개당 세수 −5% (행정 비용) — 정복만으로 끝없이 커지지 않게 합니다.
- 지상군이 지나간 3×3 타일은 즉시 그 국가 영토가 됩니다. 전선에서 멀어진 점령지는 8초마다 원래 도시 주인에게 서서히 돌아옵니다.
- 수도를 잃으면 가장 큰 도시로 천도, 도시가 없으면 멸망.

### 전쟁은 비싸고 평화는 돈이 된다
- **보호 기간** 4분: 도시 점령 불가, 민병대 2배. 처음 세팅할 시간을 줍니다.
- **전쟁 피로도**(0~100): 아군 부대 전멸 +5 (제 땅을 지키다 잃으면 +3), 적 격멸 시 제 땅·동맹 땅이면 +0.8 / **남의 땅이면 +2.5** (침략군은 이겨도 지친다), 적 도시 점령 +6, 초당 −0.12 회복. 세수 최대 −50%, 40 이상이면 인구 증가 정지. 지친 봇은 공격을 줄이고 화친을 반깁니다.
- **점령지 저항**: 점령한 도시는 150초 동안 수입 0·인구 감소. 아군 지상군이 주둔하면 2배 빨리 안정. 정복 1회당 모든 국가의 신뢰 −6 (세계 여론).
- **교역 보너스**: 불가침국 1개당 세수 +4%, 동맹국 1개당 +8%.
- **긴급 경보**: 도시 위협이 커지면 경보가 뜨고 "국방에 비축 100% 투입" 을 한 번에 누를 수 있습니다.
- **자동 내각**(국정 탭): 켜면 봇의 상황 대응 로직이 내 예산·교리·산업 비율을 6초마다 조정합니다 (외교·투자 비중은 그대로).
- **정찰 위성**(2시대): 순위 탭에서 타국의 예산·교리·공격 대상·피로도를 봅니다. 없으면 잠겨 있습니다.
- **전략 핵무기**(3시대, 정밀유도+인공지능): 적 도시 선택 → ☢ 핵 타격 (2,500, 5분 대기). 도시 체력 0, 인구·건물 절반, 반경 2 적 부대 소멸, 150초 피폭. 모든 국가 신뢰 −30. 봇은 쓰지 않습니다.
- **승리 조건**(대기실): 시간 종료 국력 1위 / 최후 생존(제한 시간의 3배까지) / 경제(국력 50,000 선착). 결과 화면에 국력 추이 그래프와 격멸·손실·점령 통계.
- 멸망하면 **관전**으로 남고, 새로고침·재접속 시 카메라·탭이 복원됩니다.

`npm run balance` (봇 4국, 20분, 재미 요소 포함 16판): 1위/4위 1.1~1.9배, 멸망 0, 점령 0~2회 — 전쟁보다 내정·외교·프로젝트가 주 승리 경로입니다.

### 외교 (외교 탭)
- 국가 쌍마다 관계와 **신뢰(0~100)** 가 있습니다. 기본은 **적대**.
- **불가침**(240초): 서로 교전·점령·영토 침범 불가. 만료되면 적대로 돌아갑니다. **동맹**(무기한): 불가침 효과 + 서로의 도시가 위협받으면 수비 임무 부대가 구원하러 갑니다.
- 봇에게 한 제안은 즉시 판정됩니다 (신뢰, 국력비, 다른 적의 수, 거리, 성향, 반복 조약 횟수를 점수화). 사람에게 한 제안은 60초 동안 대기하며 상대가 수락/거절합니다.
- **조공**(현금 300/1000)으로 신뢰를 올립니다. **적대 선언**으로 조약을 깨면 신뢰 −35~45, 제3국 신뢰 −10~15, 전군 병력 −3.
- 적대국이 아니면 공격 대상으로 지정할 수 없습니다. 봇은 훨씬 센 적에게 조공과 함께 화친을 구하고, 공동의 적이 있으면 동맹을 제안하며, 압도적으로 세지면 신뢰 낮은 조약을 배신합니다.

### 재미 요소 — 결단·국가 프로젝트·세계 의회·첩보·업적
- **결단** (`src/decisions.js`): 국가마다 2분 남짓마다 선택형 사건이 찾아옵니다 (총파업, 올림픽 유치, 과학자 망명, 유전 사고, 군부의 불만, 반전 시위, 대지진, 국경 분쟁, 기술 박람회, 조세 개혁, 밀수 적발, 증시 과열…). 45초 안에 고르지 않으면 첫 번째가 기본 선택. 효과는 현금·금고·피로도·신뢰·과학·**한시 배수(buff)** 로 나타나며, 전쟁을 부추기는 선택은 늘 대가가 따릅니다. 봇과 자동 내각은 성향대로 즉시 고릅니다.
- **국가 프로젝트** (산업 탭): 세계에 하나뿐인 불가사의 6종 — 세계 박람회(신뢰 +15, 세수 +10%, 투표권 +1), 평화 기념관(피로도 회복 3배), 국제 금융 허브(배당 +50%), 대운하(항구 교역 2배, 해안 필요), 우주 정거장(연구 +40%), 핵융합 발전소(공장 +40%, 유지비 −25%). 목표로 정하면 산업부가 산업 금고의 절반까지 2초마다 투입합니다. 다른 나라가 먼저 완성하면 투입액의 절반만 돌려받는 **경쟁**. 완성 비용의 절반이 위신으로 국력에 더해집니다.
- **세계 의회** (`src/council.js`, 외교 탭): 5분마다 결의안 상정, 60초 투표. 국가당 1표(세계 박람회 +1), 찬성 > 반대면 가결. 군비 제한(유지비 +35%), 자유 무역(교역 2배), 패권국 제재(1위 세수 −25%), 세계 휴전(점령 불가·피로도 −20), 과학 협력(연구 +30%), 인도적 지원, 핵 금지 조약, 세계 인프라 기금. 봇은 득실을 따져 찍습니다.
- **첩보** (외교 탭, 국가별): 산업 사보타주(600) / 기술 절취(800) / 선동 공작(500). 비축으로 집행, 90초 대기. 기본 성공률 65% (정찰 위성 +15%p, 상대 정찰 위성·사이버전 −15%p). 실패하면 발각되어 대상국 신뢰 −25, 제3국 −5. 군국형·기술형 봇도 가끔 씁니다.
- **업적** (`src/achievements.js`, 순위 탭): 16종 — 선구자·불가사의 건설자(세계 최초만), 과학 강국, 산업 거물, 큰손, 부국, 외교의 달인, 평화의 사도, 무혈 번영, 개척자, 해양 강국, 철벽, 백전노장, 의회의 목소리, 그림자 정부. 1개당 위신 +250. 결과 화면에 업적 수가 표시됩니다.
- **세계 뉴스**: 의회 결의, 프로젝트 완성, 업적, 첩보 적발이 상단 티커로 흐릅니다. 완성한 프로젝트는 수도 위에 금빛 표식으로 보입니다.

### 승리
제한 시간(15/20/30분) 종료 시 **국력**(현금+주식+자재+건물+부대+영토)이 가장 큰 국가. 한 국가만 남으면 즉시 종료.

## 컴퓨터 국가
사람과 똑같이 비율만 정합니다 (`src/bot.js`). 6초마다 위협·국력비·시간대를 보고 예산·교리·산업·투자·연구 목표를 바꿉니다. 산업형/군국형/기술형/금융형 성향이 판마다 섞여 배정됩니다.

`npm run balance` 기준(봇 4국 × 8판, 20분): 평균 1위/4위 국력비 3.8배, 조기 종료 0판, 승자 성향 고르게 분포. 1위/4위가 6배를 넘기거나 12분 전에 끝나는 판이 절반을 넘으면 손볼 때입니다.

## 트래픽
- 서버는 0.25초 시뮬레이션, **1초마다 diff 패치**만 보냅니다. 부대 위치는 0.1 타일 단위로 반올림하고 클라이언트가 보간합니다.
- 국가 재정·주식·시장처럼 매초 조금씩 바뀌는 값은 **3초에 한 번**(과 행동 직후)만 새로 담고, 그 사이 현금은 브라우저가 순수입으로 이어 계산합니다. 주가 이력은 배열이 아니라 표본번호 키 객체라 밀릴 때 새 표본 하나만 나갑니다.
- 위성 시대라 숨은 정보가 없으므로 방 전체에 같은 스냅샷 하나만 만듭니다.
- 실측(사람 1 + 봇 3, 10분 시점, 1배속): 최초 전체 상태 약 60~90KB(압축 전), 이후 **약 0.6KB/s(압축 전; 국가 232 / 부대 163 / 주식 58 B/s)**, 웹소켓 deflate 후 약 1/4. 일시정지 중엔 0.
- 그래픽(지형 블렌딩·음영·구름·예광탄·연기 등)은 전부 클라이언트에서만 계산하므로 트래픽에 영향이 없습니다.
- 탭을 20초 덮어 두면 수신을 멈추고, 돌아오면 전체 상태를 다시 받습니다.

## 음성 채팅
P2P(WebRTC 풀메시)라 서버 트래픽을 쓰지 않습니다. 마이크는 **https 또는 localhost** 에서만 열립니다 — 같은 Wi-Fi 의 `http://192.168…` 로는 브라우저가 막으니 배포 주소를 쓰세요. symmetric NAT 환경이면 `TURN_URL`, `TURN_USERNAME`, `TURN_PASSWORD` 환경변수로 TURN 을 지정합니다.
